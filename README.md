# trans-theme

A static Pi theme with the exact palette generated by [pi-a-theme](https://github.com/gee666/pi-a-theme) using its README example colors:

- Base: `#CD9D8A`
- Accent: `#CC397B`

All 55 generated roles are stored as fixed hex colors in [`themes/trans-theme.json`](themes/trans-theme.json). There is no extension, runtime generator, color picker, or terminal-color detection. Pi's optional scrollbar track uses the fixed muted color through its standard fallback.

The palette is designed for dark terminals. The base is a generator input, not the literal block color: the original generator bounds its lightness. This theme leaves the terminal background unchanged.

## Install

```sh
pi install https://github.com/gee666/pi-trans-theme.git
```

Run `/reload`, then select `trans-theme` in `/settings`.

To replace a-theme, first run:

```sh
pi remove https://github.com/gee666/pi-a-theme.git
```

Remove any local installation of a-theme as well, if present. Its saved colors and generated theme can be kept as backups; trans-theme does not read them.

## Palette source

Generated once with `deriveTheme('#CD9D8A', '#CC397B')` from pi-a-theme commit `6244cb9bec729775ba85064d83832e791e4c5127`. Only the theme name and explicit dark appearance differ from the generated document. The original color relationships come from [Blooming Ilacs](https://github.com/gee666/pi-theme-blooming-ilacs).
